🔐 Autentifikimi — Auth

JWT Access Token + Refresh Token me HttpOnly cookie. Token-i ruhet vetëm në React memory, jo në localStorage.

1

Login / Register

Klienti dërgon kredencialet → Laravel kthen JWT Access Token + vendos Refresh Token si HttpOnly cookie

2

Kërkesat e mbrojtura

Axios dërgon Authorization: Bearer <token> me çdo kërkesë

3

Token refresh (401)

Kur Access Token skadon, Axios interceptor-i thërret POST /api/refresh-token automatikisht dhe riprovo kërkesën

4

Logout

Revoke-on Refresh Token në DB dhe fshin cookie-n

POST /api/register Regjistrim i përdoruesit të ri PUBLIC
Request Body
FushaTipiKërkesaShënim
namestringrequiredmax:255
emailstringrequiredemail, unique, max:255
passwordstringrequiredmin:8, confirmed
password_confirmationstringrequiredduhet të përputhet me password
Response — 201
{ "success": true, "data": { "access_token": "eyJ..." } }
POST /api/login Hyrja në sistem PUBLIC
Request Body
FushaTipiKërkesaShënim
emailstringrequiredemail valid
passwordstringrequired
Response — 200
{ "success": true, "data": { "access_token": "eyJ..." } }
POST /api/refresh-token Rinovim i Access Token COOKIE

Nuk kërkon body. Lexon Refresh Token nga HttpOnly cookie automatikisht. Kthen Access Token të ri.

Response — 200
{ "success": true, "data": { "access_token": "eyJ..." } }
POST /api/logout Dalja nga sistemi JWT

Revoke-on Refresh Token në databazë dhe fshin HttpOnly cookie-n. Nuk kërkon body.

GET /api/me Të dhënat e përdoruesit të kyçur JWT
Response — 200
{ "success": true, "data": { "id": 1, "name": "Admin", "email": "admin@flowershop.test", "roles": [...] } }

🌸 Flowers — Lulet

Menaxhimi i inventarit të luleve. Stoku reduktohet automatikisht kur krijohen porosi aktive dhe restaurohet kur anullohen.

GET /api/flowers Lista e të gjitha luleve (me pagination) JWT

Kthen koleksionin e luleve me relaciot category dhe supplier të ngarkuara. Me paginim.

POST /api/flowers Krijo lule të re JWT
Request Body
FushaTipiKërkesaShënim
namestringrequiredmax:255
category_idintegerrequiredexists:categories,id
pricenumericrequiredmin:0
stock_quantityintegerrequiredmin:0
typestringoptionalmax:255
colorstringoptionalmax:100
seasonstringoptionalmax:255
lifespan_daysintegeroptionalmin:0
supplier_idintegeroptionalexists:suppliers,id
descriptionstringoptional
photostringoptionalurl, max:2048
is_activebooleanoptionaldefault: true
GET /api/flowers/{id} Detajet e një lule JWT

Kthen lulen me category dhe supplier të ngarkuara.

PUT /api/flowers/{id} Ndrysho lulen JWT

Të njëjtat fusha si POST, por të gjitha janë sometimes (jo obliguese).

DELETE /api/flowers/{id} Fshi lulen JWT

📄 Formati i Përgjigjeve

Të gjitha përgjigjet ndjekin të njëjtin format JSON konsistent përmes ApiResponse trait.

✅ Sukses
{ "success": true, "data": { ... }, "message": "OK" }
❌ Gabim Validimi — 422
{ "success": false, "message": "Validation failed", "errors": { "email": ["required"] } }
🔒 Pa autentifikim — 401
{ "success": false, "message": "Unauthorized" }
🔍 Nuk u gjet — 404
{ "success": false, "message": "Not found" }
